# evidence/ — 群内参与证据

> 这个目录用于存放**真实发出消息后的群聊截图**。它现在是空的，这是诚实状态——
> 评审核验的是「发生过的参与」，所以证据必须来自真实的群聊记录，不接受任何合成/修图。

## 存什么、怎么命名

| 截图内容 | 文件名 | 证明什么 |
|---|---|---|
| 你发出的消息出现在群聊里（带群名 + 时间戳） | `M1-sent.png` … `M5-sent.png` | 参与真实发生 |
| 他人的回应原文（带头像昵称 + 时间戳） | `M1-reply-1.png`、`M1-reply-2.png` … | 验收要点第 4 条：被同学/教师实质回应 |
| 后续讨论的关键楼层 | `M1-thread.png` … | 「产生实质进展」 |
| 问老师/助教/私聊同学的记录 | `M1-teacher.png` … | 同样计入「同学/教师回应」 |

## 三条规则

1. **原始截图，不修图**。评审要的是可核验，不是好看。
2. **先发消息，再截图**——顺序反了（先有图后发）就不是证据了。
3. 每张截图入库后，到 `反思.md` 对应条目的【后续结果】区写一行指向它，例如：
   「回应证据：`evidence/M1-reply-1.png`」。
