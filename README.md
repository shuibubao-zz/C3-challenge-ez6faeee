## 怎么用这个包

### 第 0 步：打开 `发送包.md`（2 分钟）

**不要直接复制 `反思.md` 里的文档版** —— 那是 LaTeX 公式 + Markdown 表格排版，贴进微信/QQ 会变成乱码。`发送包.md` 已把 5 条消息转成群聊纯文本，并给出：

- **发送顺序**：M1(P1 提问) → M2(P2 分享) → M3(P5 视角) → M4(P3 回应，等对口问题) → M5(P4 回馈)
- **时机**：P1 今晚 20:00–22:30 群活跃时段；连发会互相稀释
- **提高回应率**：@ 一个方向最相关的具体同学；24 小时无人回应的 three-step 应对（补细节再顶 / 私聊 / 问老师后回群同步）
- **发出记录表**：发一条填一行

### 第 1 步：发出（约 10 分钟）

用 `发送包.md` 的纯文本版（M1–M5），发送顺序与时机见该文件策略表：

1. **P1 先发**（提问，最容易引发讨论）
2. 视情况发 **P2 / P5**（分享类，自带量化证据，阅读门槛低）
3. **P3** 在有人问「AI 的数字能不能用」时发出（回应类，需要对口场景）
4. **P4 最后发**（回馈，把 P1 的结论还给群）

每条都已控制在群消息可读的长度，代码为纯文本可直接粘贴运行。

### 第 2 步：取证 + 回填（每条 3 分钟）

收到回应后，回到该条的【后续结果】回填区填：

- 实际发出时间
- 收到的回应（摘录原文）+ 回应人
- **据此我改变了什么**（具体动作 + 落在哪个文件）

同时**截图存证**：发出的消息、收到的回应、关键讨论楼，按 `M1-sent.png` / `M1-reply-1.png` 命名存入 `evidence/`（规则见该目录 README）。复审已确认评审核验的是「发生过的参与」——截图就是可核验性本身。

### 第 3 步：更新自评

回填完成后，更新 `AAR.md` ②（参与质量）与 ④（协作贡献）的自评分 —— 当前自评是**按未发出状态**打的，回填后可达 23–25 / 13–15。

### 第 4 步：勾选回填清单

`反思.md` 末尾有「回填清单」，逐条打勾。
